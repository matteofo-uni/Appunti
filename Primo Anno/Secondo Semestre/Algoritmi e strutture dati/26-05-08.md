# Altri esercizi con pile e code

- Siano due stack (S, S1). Riempire S1 con gli elementi di S in coppia
  
  ```cs
  void stack_copy(stack s, stack s1) {
      stack tmp;
      while (!stack_empty(s)) {
          push(tmp, pop(s));
      }
  
      while (!stack_empty(tmp)) {
          key i = pop(tmp);
          push(s, i);
          push(s1, i);
          push(s1, i);
      }
  }
  ```

- Dato uno stack di lettere dell'alfabeto, dire se lo stack contiene una sequenza del tipo: WORD\$DROW
  
  ```cs
  bool check(stack s, string w) {
      stack tmp;
  
      while (!stack_empty(s) && top(s) != '$') {
          push(tmp, pop(s));
      }
  
      if (stack_empty(s)) {
          // non ho trovato '$'
          return false;
      } else {
          // rimuovo '$'
          pop(s);
      }
  
      while (!stack_empty(s) && !stack_empty(tmp) && top(s) == top(tmp)) {
          pop(s);
          pop(tmp);
      }
  
      if (stack_empty(s) && stack_empty(tmp)) {
          return true;
      } else {
          return false;
      }
  }
  ```
  
  - Tempi di esecuzione:
    - Caso generale: $T(n) = 3T_{w1} + 1 + 2T_{if} + 3T_{w2} + 2$
    - Caso migliore (Il primo elemento è `'$'`): $T_m(n) = 0 + 1 + F_{if} + 2 = 3 + F_{if} = \Omega(1)$
    - Caso peggiore (Lo stack contiene una parola che soddisfa le condizioni): $T_p(n) = 3\frac{n}{2} + 3\frac{n}{2} + 1 + F_{if} + 2 = O(n)$

- Implementare la funzione `estrai` dalla coda Q che estrae il k-esimo elemento (interi positivi). Se Q contiene meno di k elementi, ritornare un errore.
  
  ```cs
  int extract(queue q, int k) {
      // posso usarla perchè q ha interi *positivi*
      enqueue(q, -1); // sentinella
  
      int i = 1;
      int ans = -1;
      int r = dequeue(q);
  
      while (r != -1) {
          if (i == k) {
              ans = r;
          }
  
          enqueue(q, r);
          i++;
          r = dequeue(q);
      }
  
      if (i <= k) {
          error("Underflow");
      } else {
          return ans;
      }
  }
  ```

- Data una coda Q di elementi non necessariamente diversi e uno stack S con elementi diversi, elimini da Q gli elementi che compaiono in S.
  
  ```cs
  void delete(queue q, stack s) {
      queue tmp;
      while (!stack_empty(s)) {
          int r = pop(s);
  
          while (!queue_empty(q)) {
              int r2 = dequeue(q);
              if (r != r2) {
                  enqueue(tmp, r2);
              }
          }
  
          if (!stack_empty(s)) {
              r = pop(s);
          }
  
          while (!queue_empty(tmp)) {
              r2 = dequeue(tmp);
              if (r != r2) {
                  enqueue(q, r2);
              }
          }
      }
  }
  ```
  
  - Tempo di esecuzione:
    - Caso generale: $T(n, m) = 3T_{w1} + 3T_{w2} + 3T_{w3} + T_{if1} + T_{if2} + T_{if3}$
    - Caso migliore (quando la coda Q contiene un solo valore ripetuto n volte, quello in cima alla pila S): $T_m(n, m) = 4\frac{n}{2} + 3m = \Omega(n + m)$
    - Caso peggiore (nessun elemento della pila S è presente nella coda Q): $T_p(n) = O(n \cdot m)$

# Grafi e alberi

Un **grafo** è una struttura formata da vertici e archi. Un grafo può essere **orientato** o **non orientato**. Sia $E_{ij} = (V_i, V_j)$ un arco/lato, se l'ordine dei vertici $V_i$ e $V_j$ importa, allora il grafo è orientato. 

Un **cammino** da $i$ a $j$ di lunghezza $l$ è una sequenza di $n$ lati che partono dal vertice $i$ e terminano nel vertice $j$.

Un cammino è **semplice** se tutti i vertici sono distinti. 

Un **ciclo** è un cammino da un vertice $V_i$ a sè stesso. 

Un grafo che non contiene cicli si dice **aciclico**.

Un grafo si dice **connesso** se per ogni coppia di vertici $(V_i, V_j)$, è sempre possibile trovare un cammino tra $V_i$ e $V_j$. Se tutti i vertici sono direttamente collegati, il grafo si dice **completo**.

Un vertice $V_j$ è **raggiungibile** (non per forza connesso) da $V_i$ se esiste un cammino tra i due vertici.

Un **albero** è un grafo non orientato, connesso e aciclico.

Un albero **radicato** ha un vertice distinto, detta la **radice**. Questo ci permette di definire un ordine di vertici.
