# Operazioni sui BST
- Inserimento:
    ```cs
    // approccio ricorsivo
    void bst_insert(pointer root, pointer x) {
        if (root == null) {
            root = x;
            return;
        }

        // caso base
        if (key(x) <= key(root) && left(root) == null) {
            left(root) = x;
        }
        if (key(x) > key(root) && right(root) == null) {
            right(root) = x;
        }

        if (key(x) <= key(root)) {
            bst_insert(left(root), x);
        } else {
            bst_insert(right(root), x);
        }
    }
    ```
- Cancellazione:
  - Ci sono tre casi:
    - Il nodo **è una foglia**: posso cancellarlo senza problemi, nullificando il puntatore al parent.
    - Il nodo **non è una foglia**, e **ha solo un figlio**: in questo caso, possiamo "contrarre" il sottoalbero, ovvero collegare il padre del nodo al suo figlio.
    - Il nodo **non è una foglia**, e **ha molteplici figli**: trovo il successore del nodo da cancellare, copio il suo valore nel nodo da cancellare, e lo rimuovo dall'albero.
    ```cs
    void bst_delete(pointer root, pointer x) {
        if (left(x) == null && right(x) == null) {
            // CASO 1: cancellazione immediata

            if (parent(x) == null) {
                // Sottocaso: sto cercando di cancellare la radice, quindi cancello l'albero
                root = null;
                return;
            }

            if (x == left(parent(x))) {
                left(parent(x)) = null;
            } else {
                right(parent(x)) = null;
            }

            return;
        } else if (left(x) == null || right(x) == null) {
            // CASO 2: contrazione

            if (parent(x) == null) {
                // Sottocaso: sto cercando di cancellare la radice, quindi la sostituisco con il suo unico figlio
                if (left(x) != null) {
                    root = left(x);
                } else {
                    root = right(x);
                }
            }

            if (x == left(parent(x))) {
                // Sottocaso: x è figlio sinistro
                // Devo capire se x ha figlio sx o dx, e renderlo il figlio sinistro del padre di x
                if (left(x) == null) {
                    left(parent(x)) = right(x);
                } else {
                    left(parent(x)) = left(x);
                }
            } else {
                // Sottocaso: x è figlio destro
                // Stesso procedimento, solo che manipolo il figlio destro del padre di x
                if (left(x) == null) {
                    right(parent(x)) = right(x);
                } else {
                    right(parent(x)) = left(x);
                }
            }

            return;
        } else {
            // CASO 3: trovo il successore
            pointer s = bst_successor(x);
            key(x) = key(s);
            // s rientrerà sicuramente nel caso 1 o nel caso 2, evitando molteplici ricorsioni
            bst_delete(s);
        }
    }
    ```
- Aggiornamento: semplicemente chiamo `bst_delete` e `bst_insert` per mantenere la struttura.
