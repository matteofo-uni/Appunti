## Scrivere un algoritmo divide-et-impera che trovi il valore massimo in un vettore di numeri interi

```c
// Ritornerà l'*indice* del valore massimo
int massimo(int V[], int L, int R) {
    if (L == R) return L;

    int mid = (L + R) / 2;
    int r1 = massimo(V, L, mid);
    int r2 = massimo(V, mid + 1, R);

    if (V[r1] >= V[r2]) {
        return r1;
    } else {
        return r2;
    }
}
```

**Calcolo del tempo:**

Equazione di ricorrenza:

$T(1) = 2$<br>
$T(n) = 2 + T(\frac{n}{2}) + T(\frac{n}{2}) + 2 = 2T(\frac{n}{2}) + 4$

**Risolviamo col metodo dell'esperto:**<br>
$a$ = n. di sottoproblemi<br>
$b$ = divisone dell'input

$log_b a = log_2 2 = 1$, $n^1 = n$<br>
La parte ricorsiva è maggiore asintoticamente di quella iterativa, siamo nel caso 1.

Mi chiedo se $f(n) = O(n^{1-\epsilon})$ per un $\epsilon > 0$.<br>
Sì: se $\epsilon = \frac{1}{2}$, $\Theta(1) = O(n^{\frac{1}{2}})$

Quindi posso applicare il metodo dell'esperto:<br>
$T(n) = \Theta(n)$

## Scrivere un algoritmo divide-et-impera che, dato un array di numeri interi ordinati, effettui la ricerca binaria/dicotomica

```c
int cerca(int a[], int k, int l, int r) {
    if (l == r) {
        if (a[l] == k) return l;
        else return -1;
    }

    int mid = (l + r) / 2;
    int r;
    
    if (a[mid] == k) r = mid;
    else if (a[mid] > k) r = cerca(a, k, l, mid - 1);
    else if (a[mid] < k) r = cerca(a, k, mid + 1, r);

    return r;
}
```

**Calcolo del tempo:**

Equazione di ricorrenza:

**Caso migliore:**<br>
$t_m(1) = 3$<br>
$t_m(n) = 4$ (se alla prima chiamata trovo `k` in `a[mid]`)<br>

Nel caso migliore, $t_m(n) = \Omega(1)$

**Caso peggiore:**<br>
$t_p(1) = 3$<br>
$t_p(n) = 5 + T(\frac{n}{2})$ (quando arrivo al caso base dopo aver fatto tutte le chiamate possibili, o se non trovo l'elemento)

**Proviamo col metodo dell'esperto:**<br>
La parte iterativa è $5 = \Theta(1)$<br>
La parte ricorsiva è $n^{log_2 1} = n^0 = 1 = \Theta(1)$

Siamo nel caso 2: $T(n) = \Theta(1 \cdot log\space n)$, essendo il caso peggiore: $O(log\space n)$

## Suppongo di voler eseguire il seguente calcolo:
`b = (2 + a[1]) * (2 + a[2]) + ... + (2 + a[n])`

```c
int calcolo(int a[], int l, int r) {
    if (l == r) {
        return 2 + a[l];
    }

    int mid = (l + r) / 2;
    int r1 = calcolo(a, l, mid - 1);
    int r2 = calcolo(a, mid + 1, r);

    return r1 * r2 * a[mid];
}
```

## Dato un array di interi ordinati senza elementi ripetuti, scrivere un algoritmo divide-et-impera che trova i casi in cui `a[i] == i`
```c
int trova(int a[], int l, int r) {
    if (l == r) {
        if (a[l] == l) {
            return l;
        } else {
            return -1;
        }
    } else {
        int mid = (l + r) / 2;
        int ret;

        if (a[mid] == mid) {
            ret = mid;
        } else {
            if (a[mid] > mid) {
                ret = trova(a, l, mid - 1);
            } else {
                ret = trova(a, mid + 1, r);
            }
        }

        return ret;
    }

    return -1;
}
```
