# Quicksort
Algoritmo di ordinamento divide-et-impera **non stabile** e **in-loco**.<br>
Il nome è dato dalla sua velocità.

Il suo caso peggiore è $O(n^2)$ ed il caso medio è $\Theta(n\space log\space n)$.

**Codice:**

```c
// Metodo di Hoare
int partition(int a[], int l, int r) {
	int pivot = a[l];
	int sx = l - 1;
	int dx = r + 1;

	while (sx < dx) {
		do { sx++; } while (a[sx] < pivot);
		do { dx--; } while(a[dx] > pivot);

		if (sx < dx) {
			int temp = a[sx];
			a[sx] = a[dx];
			a[dx] = temp;
		}
	}

	return dx;
}

void quicksort(int a[], int l, int r) {
	if (l < r) {
		int q = partition(a, l, r);
		quicksort(a, l, q);
		quicksort(a, q + 1, r);
	}
}
```

**Calcolo dei tempi:**

La partition ha tempo: $T_p(n) = 4C + 8n = O(n)$<br>
Scriviamo l’equazione di ricorrenza per la parte ricorsiva: $T_{as}(n) = n + T(Q) + T(n - Q)$

Vediamo i casi di $Q$:
- Se $Q = \frac{n}{2}$, il tempo è $n + 2T(\frac{n}{2}) = \Theta(n\space log\space n)$
- Se $Q = 1$, il tempo è $n + T(1) + T(n-1) = n + T(n - 1)$. Risolvendo con il metodo iterativo: $\frac{n(n+1)}{2} + (n - 1) + n = \Theta(n^2)$

# Quicksort randomizzato
Una variante del quicksort in cui il pivot viene scelto casualmente. Questo rende il caso peggiore molto più raro rispetto all’implementazione standard.

```c
int partition(int a[], int l, int r) {
	int rand = random(l, r);
	swap(a, l, rand); // evita il caso peggiore
	int pivot = a[rand];

	// continuo come al solito
}
```

# Strutture dati
**Operazioni di base:**
- Search: ricera di un certo dato (`search(s, k)`)
  - `s`: Struttura dati
  - `k`: Chiave
- Insert: inserisco un dato (`insert(s, x)`)
  - `s`: Struttura dati
  - `x`: Informazioni da aggiungere
- Delete: elimina un dato (`delete(s, x)`)
  - `s`: Struttura dati
  - `x`: Informazioni da eliminare
- Min/Max: trova il valore minimo o massimo (`min(s)` e `max(s)`)
- Previous/Next: trova il più piccolo/grande tra gli elementi successivi/precedenti (`previous(s, x)` o `next(s, x)`)
  
**Strutture statiche e dinamiche:**
- Statiche: riservo una quantità fissa di memoria a disposizione della struttura
- Dinamiche: la quantità di memoria a disposizione della struttura varia durante l’esecuzione
