# Strutture dati
Un'array è un esempio di una struttura dati statica (tipicamente), mentre una lista è un esempio di una struttura dati dinamica.

Le strutture dati statiche permettono di usare l'indexing diretto: sapendo l'indirizzo base della struttura, possiamo utilizzare gli indici come offset in memoria.

Le strutture dati dinamiche, invece, non permettono l'accesso diretto ai dati.

# Liste dinamiche
- Operazioni
  - **Allocazione della memoria:** crea un nodo e ne ritorna l'indirizzo in memoria
  - **Liberamento della memoria:** dealloca un nodo dalla memoria
  - **List search:**
    - Parametri:
      - $L$: puntatore al primo nodo della lista
      - $K$: chiave da cercare
    - Valore di ritorno: se presente, un puntatore ad un nodo di $L$ con chiave $K$, altrimenti `null`.
    - Scorro la lista a partire dalla testa, controllando ad ogni iterazione se la chiave del nodo considerato è $K$.
    - Codice:
        ```cs
        pointer list_search(pointer L, key K) {
            int p = L;
            while (p != null && key(p) != K) {
                p = next(p);
            }

            return p;
        }
        ```
    - Tempo:
      - Caso peggiore: $O(n)$ ($K \notin L$)
      - Caso migliore: $\Omega(1)$ ($K$ è nella prima casella)
  - **Inserimento in testa alla lista:**
    - Parametri:
      - $L$: puntatore al primo nodo della lista
      - $X$: puntatore ad un nodo da inserire
    - Valore di ritorno: nessuno
    - Codice:
        ```cs
        void list_insert(pointer l, pointer x) {
            next(x) = l;
            prev(x) = null;

            if (l != null)
                prev(l) = x;

            l = x;
        }
        ```
    - Tempo: Costante $\Theta(1)$
  - **Cancellazione di un nodo:**
    - Parametri:
      - $L$: puntatore al primo nodo della lista
      - $K$: chiave dell'elemento da cancellare
    - Codice:
        ```c
        void list_delete(pointer l, key k) {
            pointer x = list_search(l, k);

            if (prev(x) != null)
                next(prev(x)) = next(x);
            if (next(x) != null)
                prev(next(x)) = prev(x);

            // ... ulteriori complicazioni per casi speciali
        }
        ```
