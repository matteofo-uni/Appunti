# Errori comuni per pile/code

- Overflow: quando si cerca di inserire un elemento, ma non c'è più spazio disponibile
- Underflow: tentativo di pop/dequeue da una struttura vuota

# Implementazione delle pile

- Con array:
  
  - Uso un indice speciale `T`, che ha la posizione dell'ultimo elemento inserito.
  
  - Quando la pila non contiene alcun elemento, `T` sarà 0 (o -1 con indexing a partire da 0)
  
  - Push:
    
    ```cs
    void push(key a[], int i, key x) {
        if (i == length(a)) {
            error("Overflow");
        } else {
            i++;
            a[i] = x;
        }
    }
    ```
  
  - Pop:
    
    ```cs
    key pop(key a[], int i) {
        if (i == 0) {
            error("Underflow");
        } else {
            key r = a[i];
            i--;
            return r;
        }
    }
    ```

- Con liste dinamiche:
  
  - Uso una lista semplice (singly linked)
  
  - Per fare il push, inserisco l'elemento in testa.
  
  - Per fare il pop, rimuovo l'elemento in testa.
  
  - Push:
    
    ```cs
    void push(pointer s, pointer x) {
        next(x) = s;
        s = x;
    }
    ```
  
  - Pop:
    
    ```cs
    pointer pop(pointer s) {
        if (s == null) {
            error("Underflow");
        } else {
            pointer r = s;
            s = next(s);
            return r;
        }
    }
    ```
  
  - Empty:
    
    ```cs
    bool stack_empty(pointer s) {
        if (s == null) return true;
        else return false;
    }
    ```
    
# Implementazione delle code

- Con array:
  
  - Mantengo due indici: uno per l'inizio della coda, e uno per la fine. Gli indici "girano" attorno alla lunghezza dell'array, formando una sorta di array circolare.
  
  - Enqueue:
    
    ```cs
    void enqueue(key q[], int i, int f, key x) {
        if (i == f - 1 % length(q)) {
            error("Overflow");

    }
    ```
  
  - Dequeue:
    
    ```cs
    key dequeue(key q[], int i, int f, key x) {
        if (i == f) {
            error("Underflow");
        } else {
            key r = q[i];
            i = (i + 1) % length(n);
            return r;
        }
    }
    ```
  
  - Empty:
    
    ```cs
    bool queue_empty(key q[], int i, int f) {
        if (i == f) return true;
        else return false;
    }
    ```

- Con liste dinamiche:
  
  - Inserisco gli elementi in coda, tenendo traccia della sua posizione in memoria con un puntatore.
  
  - Rimuovo gli elementi dalla testa.
  
  - Enqueue:
    
    ```cs
    void enqueue(list q, pointer x) {
        if (tail(q) != null) {
            next(tail(q)) = x;
            tail(q) = x;
        } else {
            head(q) = x;
            tail(q) = x;
        }
    }
    ```
  
  - Dequeue:
    
    ```cs
    key dequeue(list q) {
        if (head(q) == null) {
            error("Underflow");
        } else {
            key r = head(q);
            head(q) = next(head(q));
            return r;
        }
    }
    ```
  
  - Empty:
    
    ```cs
    bool queue_empty(list q) {
        if (head(q) == null) return true;
        else return false;
    }
    ```
    

# Esercizi d'esempio

- Date una pila p1 e una chiave k, eliminare le occorrenze di k, usando come appoggio un'altra pila.
  
  ```cs
  void delete_all(stack s1, key k) {
      stack s2;
      while (!stack_empty(s1)) {
          key t = pop(s1);
          if (t != k) {
              push(s2, t);
          }
      }
  
      while (!stack_empty(s2)) {
          key t = pop(s2);
          push(s1, t);
      }
  }
  ```
  
  - Tempo di esecuzione:
    - Caso generale: $T(n) = 1 + 3t_{w1} + t_{if} + 3t_{w2}$, dove $t_{w1} = n$
    - Caso migliore (se la pila contiene solo k, $t_{if} = 0 = t_{w2}$): $1 + 3n = \Omega(n)$
    - Caso peggiore (se la pila non contiene k, quindi $t_{if} = n = t_{w2}$): $1 + 4n + 3n = O(n)$

- Implementare push e pop per due stack memorizzati in un array condiviso.
  
  ```cs
  // s è l'indice dello stack. (1 o 2)
  void push(key a[], int s, key x, int t1, int t2) {
      if (t1 == t2 - 1) {
          error("Overflow");
      }
  
      if (s == 1) {
          t1++;
          a[t1] = x;
      } else {
          t2--;
          a[t2] = x;
      }
  }
  ```
  
  ```cs
  key pop(key a[], int s) {
      if (s == 1) {
          key r = a[t1];
          t1--;
          return r;
      } else {
          if (t2 == length(a) + 1) {
              error("Underflow");
          } else {
              key r = a[t2];
              t2++
              return r;
          }
      }
  }
  ```
