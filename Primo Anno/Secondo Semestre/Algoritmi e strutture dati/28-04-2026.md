# Operazioni sulle singly-linked list
- Cancellazione
  ```cs
  void list_delete(pointer l, pointer x) {
  	if (x == l) {
  		// se x è il primo elemento
  		l = next(x);
  		free(l);
  	} else {
  		while (next(l) != x) {
  			l = next(l);
  		}
  
  		next(l) = next(x);
  		free(x);
  	}
  }
  ```
  - Tempo:
    - Caso migliore: $\Omega(1)$
    - Caso peggiore: $O(n)$

- Ricerca
	```cs
	void search(pointer l, key k) {
		pointer att = l;
		pointer prec = null;
		
		while (key(att) != k && att != null) {
			prec = att;
			att = nect(att);
		}
	}
	```

# Altre operazioni sulle doubly-linked list
- Minimo
	```cs
	pointer min(pointer l) {
		if (l == null) return null;

		pointer pmin = l;
		pointer patt = next(l);

		while (patt != null) {
			if (key(patt) < key(pmin)) {
				pmin = patt;
			}

			patt = next(patt);
		}

		return pmin;
	}
	```
	- Tempo: $\Theta(n)$
- Successore
	```cs
	pointer succ(pointer l, key k) {
		if (l == null) return null;

		pointer psucc = l;
		while (key(psucc) <= k && psucc != null) {
			psucc = next(psucc);
		}

		pointer patt = next(psucc);
		while (patt != null) {
			if (key(patt) < key(psucc) && key(patt) > k) {
				psucc = patt;
			}

			patt = next(patt);
		}

		return psucc;
	}
	```
