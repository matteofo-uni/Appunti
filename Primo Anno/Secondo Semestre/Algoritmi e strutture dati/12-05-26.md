# Rappresentazione di alberi in memoria
In un albero **binario e radicato**, ogni nodo è una struttura dati con i seguenti campi:
| Nome | Tipo | Significato |
| ---- | ---- | ----------- |
| Chiave | Qualsiasi | Valore salvato nel nodo |
| Figlio sinistro | Puntatore | Si riferisce al nodo figlio di sinistra (`null` se non esiste)
| Figlio destro | Puntatore | Si riferisce al nodo figlio di destra (`null` se non esiste)
| Genitore | Puntatore | Si riferisce al nodo genitore, ovvero al livello superiore; vale `null` nel caso della radice

# Definizione ricorsiva degli alberi binari
1. Un albero vuoto ($\empty$) è un albero binario
2. Un nodo radice $R$ con alberi binari figli a sinistra ($S$) e a destra ($D$) è un albero binario: $(R, S, D)$

# Proprietà di alberi binari e dei loro nodi
Per ogni nodo è possibile determinare:
- I nodi **antenati** salendo
- I nodi **discendenti** scendendo (che formano un **sottoalbero**)
- **Il grado**: il numero di figli (in un albero binario può essere solo 0, 1 o 2)
- **La profondità**: la lunghezza del cammino più breve dalla radice al nodo.

Proprietà degli alberi binari:
- **L'altezza** di un albero è la profondità massima.
- Un albero binario **pieno** è un albero binario in cui ogni nodo ha 0 o 2 figli.
- Un albero binario **completo** è un albero binario in cui ogni nodo ha 2 figli, **tranne i nodi foglia**, che ne hanno 0.
- Un albero binario **quasi completo** è un albero binario completo in cui l'ultimo livello è 
**parzialmente completo da sinistra a destra**.
- Un albero binario di altezza $h$ ha $\sum_{i=0}^{h} 2^i = 2^{h + 1} - 1$ nodi.
- Un albero binario ben bilanciato con $n$ nodi ha altezza $\approx log_2\space n$, altrimenti ha altezza $\approx n$.

# Alberi binari di ricerca
Un albero binario **di ricerca** (o **BST**, Binary Search Tree) è un albero binario in cui, per ogni nodo, il sottoalbero sinstro contiene nodi minori della radice, e il sottoalbero destro contiene nodi maggiori della radice.

In genere, le operazioni sugli alberi binari di ricerca richiedono tempo logaritmico.

# Definizione ricorsiva degli alberi binari di ricerca
Un albero binario di ricerca $T$ è un albero binario tale che $\forall x \in T$:
- $\forall y \in$ sottoalbero sinistro di $x$, $key(y) < key(x)$
- $\forall y \in$ sottoalbero destro di $x$, $key(y) > key(x)$

# Algoritmi di visita degli alberi binari
- Visita anticipata o preorder:
    1. Visito la radice
    2. Visito il sottoalbero sinistro
    3. Visito il sottoalbero destro
    ```cs
    void preorder(pointer root) {
        if (root != null) {
            print(key(root));
            preorder(left(root));
            preorder(right(root));
        }
    }
    ```
- Visita posticipata o postorder:
    1. Visito il sottoalbero sinistro
    2. Visito il sottoalbero destro
    3. Visito la radice
    ```cs
    void postorder(pointer root) {
        if (root != null) {
            preorder(left(root));
            preorder(right(root));
            print(key(root));
        }
    }
    ```
- Visita simmetrica o in order:
    1. Visito il sottoalbero sinistro
    2. Visito la radice
    3. Visito il sottoalbero destro
    ```cs
    void inorder(pointer root) {
        if (root != null) {
            preorder(left(root));
            print(key(root));
            preorder(right(root));
        }
    }
    ```
    **In caso di albero binario di ricerca, la visita simmetrica restituisce i nodi dell'albero in ordine crescente!**

**Calcoliamo i tempi di esecuzione:**
- Nel caso di un albero binario pieno, ho $T(n) = 3+ 2T(\frac{n}{2})$, risolvendo con il metodo dell'esperto ho: $T(n) = \Theta(n)$
- Nel caso di un albero completamente sbilanciato, ho $T(n) = 3 + T(n - 1)$, risolvendo con il metodo iterativo ho: $T(n) = \Theta(n)$

# Esercizi
- Eseguire la ricerca in un BST.
    ```cs
    pointer bst_search(pointer root, int k) {
        if (root == null) {
            return null;
        } else {
            if (key(root) == k) return root;
            else if (key(root) > k) return bst_search(left(root));
            else if (key(root) < k) return bst_search(right(root));
        }
    }
    ```
    - Caso peggiore (non trovo il valore esaminando il ramo più lungo): $O(h)$ (dove $h$ è l'altezza dell'albero), ma se l'albero è ben bilanciato ho $O(log\space n)$
    - Caso migliore (trovo il valore nella radice): $\Omega(1)$
