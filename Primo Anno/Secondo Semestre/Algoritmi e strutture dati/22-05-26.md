# Code con priorità
Una struttura dati basata su una heap usata per mantenere le chiavi **parzialmente ordinate** in modo efficiente.

**Operazioni possibili:**
- `Max(h)`: ritorna il massimo in tempo costante.
- `ExtractMax(h)`: ritorna il massimo rimovendolo dalla struttura, in tempo $O(log\space n)$. 
  - Viene scambiato il primo elemento con l'ultimo: `swap(h[1], h[heapsize(h)]);`
  - Viene ridotta l'heapsize `heapsize(h)--;`
  - Infine viene chiamato `heapify(h)` sulla struttura risultante per mantenere l'ordine.
- `Insert(h, k)`: inserisce la chiave `k` in `h`.
    ```cs
    void heap_insert(int h[], int k) {
        // Inserisco il valore in fondo alla heap
        heapsize(h)++;
        h[heapsize(h)] = k;
        int pos = heapsize(h);
        
        // Cerco un parent con chiave maggiore di k
        while (pos != 1 && h[pos / 2] < k) {
            h[pos] = h[pos / 2];
            h[pos / 2] = k;
            pos = pos / 2;
        }
    }
    ```
    **Tempo di esecuzione**:
    - Caso migliore: $\Omega(1)$
    - Caso peggiore: $O(log\space n)$

# Rappresentazioni dei grafi in memoria
- **Liste di adiacenza**: i nodi sono salvati in un array, ed ogni nodo ha una lista che contiene i nodi a cui è connesso (direttamente).
  - Se il grafo è **non orientato**, devo salvare ogni relazione in entrambi i nodi.
  - Se il grafo è **pesato**, aggiungo un campo ad ogni nodo nelle liste che ne indica il peso.
- **Matrice di adiacenza**: una matrice $n$ x $n$, dove $n$ è il numero di vertici del grafo. Ogni cella della matrice contiene **0** se i vertici alle sue coordinate non sono adiacenti, e **1** se lo sono. 
  - Se il grafo è **non orientato**, la matrice sarà simmetrica.
  - Se il grafo è **pesato**, invece di avere solo **1** per i nodi adiacenti, avrò il valore del peso.

# Visite sui grafi
I due principali metodi di visita di un grafo sono:
- **Breadth First Search** (BFS): visita (non necessariamente tutto) il grafo in ampiezza, visito i nodi sullo stesso livello. Permette di ottenere le **distanze** da un vertice a tutti gli altri.

- **Depth First Search** (DFS): visita **tutto** il grafo in profondità, fino a trovare un nodo senza connessioni, tornando indietro. Ritorna informazioni sulle varie componenti connesse.
