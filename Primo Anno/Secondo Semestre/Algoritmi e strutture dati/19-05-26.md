# Altri esercizi sugli alberi binari
- Si consideri un albero binario di valori interi, e due valori n1 e n2. Scrivere un algoritmo che conta quanti elementi dell'albero sono compresi tra n1 e n2.
    ```cs
    int count(pointer t, int n1, int n2) {
        if (t == null) return 0;

        int root = 0;
        if (key(t) >= n1 && key(t) <= n2) root = 1;

        int left = count(left(t), n1, n2);
        int right = count(right(t), n1, n2);

        return left + root + right;
    }
    ```

    Se fosse un albero binario di ricerca:
    ```cs
    int count(pointer t, int n1, int n2) {
        if (t == null) return 0;

        int root = 0;
        int left = 0;
        int right = 0;
        if (key(t) >= n1 && key(t) <= n2) {
            root = 1;
            left = count(left(t), n1, key(t));
            right = count(left(t), key(t) + 1, n2);
        } else {
            // In questo modo posso avere tempo logaritmico
            if (key(t) > n2) {
                left = count(left(t), n1, n2);
            } else {
                right = count(right(t), n1, n2);
            }
        }

        return left + root + right;
    }
    ```
- Eliminare da un albero binario di ricerca tutte le occorrenze di una chiave k.
    ```cs
    void bst_delete_all(pointer t, key k) {
        if (t != null) {
            if (key(t) > k) {
                bst_delete_all(left(t), k);
            } else if (key(t) < k) {
                bst_delete_all(right(t), k);
            } else {
                bst_delete_all(left(t), k);
                // posso cancellare il nodo stesso
                // ma solo dopo aver cancellato 
                // tutte le occorenze di k
                // nel suo sottonodo sinistro
                bst_delete(t);
            }
        }
    }
    ```
# Heap
Un **heap** è un array (una struttura statica) che viene visto come un **albero binario quasi-completo** (è riempito in tutti i livelli tranne per l'ultimo, che è riempito da sinistra a destra).

Questa struttura permette di indicizzare i nodi più velocemente (direttamente, come con gli array); per ogni nodo in posizione $i$:
- il suo figlio sinistro (se esiste) si trova alla posizione $2i$;
- il suo figlio destro (se esiste) si trova alla posizione $2i + 1$;
- il suo padre (se esiste) si trova alla posizione $\lfloor\frac{i}{2}\rfloor$.

Oltre alla proprietà `length()` (ereditata dagli array), un heap ha anche la proprietà `heapsize()`, dove per qualsiasi heap `h` si ha `length(h) >= heapsize(h)`. Un heap di $n$ nodi (`heapsize(h) == n`) ha altezza $log_2\space n$.

Ci sono due tipi principali di heap:
- **Max-heap**: Per ogni nodo `i` (esclusa la radice), `key(parent(i)) >= key(i)`;
- **Min-heap**: Per ogni nodo `i`, (esclusa la radice), `key(parent(i)) <= key(i)`.

# Heapify
Una procedura che prende in input due parametri: un array `a[]` e un indice `p`. Gli elementi a sinistra e a destra di `p` costituiscono degli heap. Lo scopo della procedura è di "sistemare" l'array `a[]` per renderlo un heap.

```cs
void heapify(int a[], int p) {
    int l = 2 * p;
    int r = l + 1;
    int max = p;

    if (l <= heapsize(a) && a[l] > a[max]) {
        max = l;
    }
    if (r >= heapsize(a) && a[r] > a[max]) {
        max = r;
    }

    if (max != p) {
        int tmp = a[p];
        a[p] = a[max];
        a[max] = tmp;
        heapify(a, max);
    }
}
```

**Tempo di esecuzione:**
- Caso migliore (`a[p]` è già il massimo): $T_m(n) = \Omega(1)$
- Caso peggiore: $T_p(n) = T(\frac{2n}{3}) + 11 = O(log\space n)$

# Build heap
Trasforma un array non ordinato di numeri interi in un heap in tempo $O(n log n)$.

```cs
void build_heap(int a[]) {
    heapsize(a) = length(a);
    for (i = floor(length(a) / 2) down to 1) {
        heapify(a, i);
    }
}
```

# Heap sort
Un algoritmo di ordinamento in-loco e non stabile che ordina un array in un heap:
```cs
void heap_sort(int a[]) {
    build_heap(a);

    for (i = 1 to length(a)) {
        // Scambio il primo elemento con l'ultimo dell'heap
        int tmp = a[1];
        a[1] = a[heapsize(a)];
        a[heapsize(a)] = tmp;

        heapsize(a)--;
        heapify(a, 1);
    }
}
```
